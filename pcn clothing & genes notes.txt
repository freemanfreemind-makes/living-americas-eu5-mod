Clothing and Gene additions/changes for pcn and livam mods

file locations
    models
    - main_menu/gfx/portraits/accessories #sets poses and other data for accessories
        - not needed until new clothing items introduced.
    - in_game/gfx/models/portraits/attachments #model files for clothing sets
        - use existing where possible to start

    scripts & templates
    - in_game/common/genes/0X_genes_accessories_XXXX.txt            #setting a clothing or accessory set for a culture
    - main_menu/gfx/portraits/portrait_modifiers                    #setting cultures and selecting templates for classes
    - in_game/common/scripted_triggers/XX_clothing_triggers.txt     #setting condition triggers, sub culture, estate, birth year, etc.

Order to create:

1. in_game/gfx/graphical_culture_types/

2. in_game/common/genes/0X_genes_accessories_XXXX.txt
    a. mod_name_genes_accessories_headwear - hats and jewelery
    b. mod_name_genes_accessories_clothes
    c. mod_name_genes_accessories_hair
    d. mod_name_genes_accessories_beards

3. main_menu/gfx/portraits/portrait_modifiers
    a. mod_name_headwear
    b. mod_name_clothes
    c. mod_name_headwear_additive
    d. mod_name_beards

4. in_game/common/ethnicities
    a. if needed create new ethnicity by copying existing and modifying.
    b. 00_ethnicities_mod_name - add in new hair genes

5. in_game/common/cultures/
    a. region_name.txt #select which cultures will recieve the new clothing set and/or ethnicity
