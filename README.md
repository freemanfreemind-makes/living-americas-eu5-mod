Living Americas - a mod for Europa Universalis 5

Steam Workshop Page: https://steamcommunity.com/sharedfiles/filedetails/?id=3735276532

Fills out the new world with many historic nations, and when documentation doesn't exist plausible culture based nations, to both 
- prevent colonising nations from ahistorically conquering the entirety of the continents 200 years in &
- provide a challenge for players of both European and American factions.

Pacific Coast Nations content included goes deep with a narrow focus on an area that I know well. This mod goes wide in scope with the rest of the americas, but fairly shallow in terms of gameplay and cultural modifications... though this will likely change over time as I can get to it.
- Content will be developed here & ported over to the smaller PCN mod during every update of this main effort.

Features:
- Adds well over 250 playable and pops based nations to the americas, including 165 created from scratch, remainder created from existing pops based nations.
- Adds 19+ formable nations. (depending on when this readme is updated) including Illiniwek, Caddo, Dakoda, Muskogee, Erielhonan, Chonnonton, Wendat, Powhatan, Massachusett, Cherokee, Opata, ... and more.
- Includes all content from 'Pacific Coast Nations' mod.
- Includes all content from the abandoned Patagonia Expanded, updated, expanded, and cleaned up to function with the latest versions, as well as corrected the map visibility of each added faction. Thanks to The_Subarashii_One for granting their permission - https://steamcommunity.com/sharedfiles/filedetails/?id=3602204421
- Adds in several markets deactivated in base game files
- Nerfed Cahokia & overhauled faction (Pa'hé'žíde) and set starting diplomatic arrangements to better match known history.
- Added matriarchal governments beyond Haudenausaunee factions.
- Adds several tribal confederation international organizations to North America
- Adds Country Personality traits to several major factions, with more to follow in future updates.
- Added custom versions of the "balanced" and "expansionist" AI to be slightly more in favour of subjugation and be slightly more aggressive, and the "friendly" type made to be a bit more trade focused. *** Disabled in game v1.4+ due to base game AI changes *** - to be rebalanced in a future update.
- Custom map views added for all new factions.
  
... and various other small changes.

Requires a semi-decent CPU to handle the extra factions.

As I've referenced and been inspired by so much he's had to say, check out Malcolm P.L. on youtube - he's an iroquios historian and experimental archeologist with a lot of amazing insights into the peoples of the eastern great lakes specific to this time period.
